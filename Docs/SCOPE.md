# Relational EX — Scope

## Product thesis

Relational EX is an experimental instrument for exploring relationships between **pitch, rhythm, spectrum, tuning and motion**.

Microtonality is not a decorative mode. It is one consequence of a larger relational system.

## Core systems

1. **Frequency Field** — editable representation of tuning and pitch relationships.
2. **Relational Engine** — bounded coupling between pitch, time, FM, resonance and tuning.
3. **FM + Inharmonic Resonator** — the primary sound engine.
4. **Relational Sequencer** — event-based sequencing with Field/Grid/Radial views.
5. **Tuning Interoperability** — TET, Scala, KBM, MIDI Tuning Standard and MTS-ESP.
6. **Motion Layer** — LFO, deterministic chaos and tuning drift.
7. **Exploratory Presets** — presets that teach relationships rather than imitate genres.

## Current design priority

Deepen the relationships between existing systems before adding new synthesis families. The 5×5 relation matrix is now editable and persisted.

## Explicitly out of scope

Relational EX is not intended to become:

- a general subtractive synthesizer;
- a wavetable workstation;
- a sampler;
- a granular engine;
- a drum sampler;
- a large multi-effect suite;
- a generic preset collection;
- a clone of Wilsonic, Buchla instruments, Autechre or Aphex Twin equipment/software.

## Completion criteria

A feature is complete only when realtime behavior is safe, the VST3/Standalone paths are considered, tooltips/manual documentation exist in English, state/preset effects are documented, reproducible tests exist, and architecture changes are recorded.
