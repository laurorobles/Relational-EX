# UI Specification — RELATIONAL

## Design intent

The interface is a technical instrument panel for exploring relationships between frequency, spectrum, rhythm and motion. It should feel precise and slightly alien, not retro-futuristic decoration and not a visual copy of an existing synthesizer.

## Visual language

- Strict modular framing with consistent outer margins and internal spacing.
- Dark neutral base with restrained high-contrast signal accents used to indicate state, modulation and selection.
- Typography is compact, technical and legible. Numeric readouts are treated as first-class information.
- Empty space is purposeful: every region is either a control, a readout, a relation, or a breathing margin that clarifies hierarchy.
- Graphs and geometric views are interactive, not decorative.

## Main modules

1. Frequency Field — tuning geometry and frequency relationships.
2. Spectral Engine — FM, partials and resonator structure.
3. Modulation — envelopes, LFO, random, audio-rate and future attractor/chaos sources.
4. Relational Sequencer — shared event model with Grid, Field and Radial views.
5. Global — clock, level, tuning source and macro controls.

## Personality references

The conceptual references are experimental digital synthesis, modular instruments, microtonal visualization and data-driven interfaces. Autechre, Aphex Twin, Wilsonic, Nord Modular, Yamaha FM instruments and Elektron-style sequencing are references for functional ideas, not visual templates.

## Interaction rules

- Every interactive control has an English hover explanation.
- Direct manipulation should reveal the mathematical result where practical (ratio, cents, frequency, period).
- The same musical data may be viewed through multiple visualizations without changing its underlying state.
